# Sistema de Gerenciamento de Pedidos de Foto
Este projeto é um sistema web para gerenciamento de pedidos de fotos, desenvolvido com React, HTML5 e CSS3.

## Funcionalidades:
<ul>
  <li>Cadastro, edição e exclusão de pedidos de fotos.</li>
  <li>Visualização detalhada dos pedidos com status e prazos.</li>
  <li>Interface responsiva e moderna, com navegação intuitiva.</li>
  <li>Gerenciamento de clientes e categorias de fotos.</li>
  <li>Utilização de componentes React para organização e reutilização do código.</li>
  <li>Estilização customizada com CSS para design limpo e profissional.</li>
  <li>Backup via arquivo JSON dos Pedidos</li>
</ul>

## Tecnologias utilizadas:
<ul>
  <li>React (biblioteca JavaScript para construção da interface)</li>
  <li>HTML5 e CSS3 (estrutura e estilo)</li>
  <li>Gerenciamento de estado com React Hooks.</li>
</ul>

## Como executar:
<ol>
  <li>Clone o repositório.</li>
  <li>Instale as dependências com npm install ou yarn install.</li>
  <li>Execute o projeto localmente com npm start ou yarn start.</li>
  <li>Acesse no navegador via http://localhost:3000.</li>
</ol>
